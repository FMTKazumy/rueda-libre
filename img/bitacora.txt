 Hoja de estilos externa con variables, tipografías y colores de marca.

Propiedad que se hereda: color (y font-family)

Se declara solo en body con var(--color-textosecundario).
En Computed, el <p> muestra color:rgb(91, 100, 112) y la fuente Open Sans, sin tener una regla propia. Los hereda del body.

Propiedad que no se hereda: margin (también sirve background-color)

El body tiene un margen propio y el <p> no lo recibe: en Computed muestra otro valor, que viene de los estilos por defecto del navegador.
Con background-color pasa igual: se declara en body, pero el <p> queda transparente. El crema se ve a través de él porque el fondo del body está detrás, no porque se herede.

Conclusión: las propiedades de texto, como color y tipografía, pasan de padre a hijo. Las de caja, como margen, relleno y fondo, no.

Cambia los valores por los que veas tú en pantalla. Si tu bitácora tiene un formato fijo (tabla, columnas, un documento aparte), pégame cómo es y te lo adapto.

• Tailwind CSS (Utility-First): No impone ningún diseño pre-construido. Ofrece herramientas de bajo nivel directamente en el marcado HTML, lo que da una libertad creativa total para crear interfaces personalizadas y únicas sin necesidad de escribir hojas de estilo CSS externas.

Fecha: 4 de noviembre de 2026 [4]
• El flujo con Play CDN (Prototipo): Funciona mediante una etiqueta <script> que obliga al navegador a descargar toda la librería e interpretar el HTML en tiempo real cada vez que se carga la página [Tailwind]. Es una herramienta excelente para hacer pruebas rápidas o aprender, pero ralentiza la carga del sitio web.
• El flujo con la CLI de Tailwind (Producción): Funciona de forma local mediante una terminal activa (--watch) que actúa como una fábrica de estilos [Tailwind CSS]. La consola lee las clases que escribimos en el HTML, extrae el código CSS real de esas clases y genera un archivo final empaquetado y limpio llamado output.css.

Diferencia clave entre ambos enfoques:

• Rendimiento y velocidad: Con la CLI, el navegador del usuario final solo procesa un archivo CSS puro de apenas unos cuantos kilobytes que contiene exclusivamente las clases utilizadas. No hay demoras ni procesamiento extra en el navegador, logrando que el sitio de Rueda Libre cargue de forma ultrarrápida.
• Optimización para producción: El Play CDN está prohibido para proyectos reales debido a que no está optimizado y no soporta plugins. La CLI ofrece un entorno robusto, elimina automáticamente todo el código CSS que no se usó (purga) y deja el proyecto listo para subirse de forma profesional a cualquier servidor de internet.
